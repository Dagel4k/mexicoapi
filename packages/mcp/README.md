# mexicoapi-mcp

Servidor MCP por stdio, de solo lectura, con datos oficiales de México. Los datos salen del paquete [`mexicoapi`](https://github.com/Dagel4k/mexicoapi/tree/main/packages/sdk#readme).

```json
{
  "mcpServers": {
    "mexicoapi": {
      "command": "npx",
      "args": ["-y", "mexicoapi-mcp"]
    }
  }
}
```

Pide Node 22.13 o posterior. El código es [MIT](https://github.com/Dagel4k/mexicoapi/blob/main/LICENSE).
